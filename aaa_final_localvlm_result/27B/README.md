不是GPU实际利用率积分。有效请求阶段累计31.92小时，包含处理/推理/校验；
4次旧中断状态缺少elapsed，未假造其时长，记录的全部尝试时长是下界。

## 样本口径

实际有效2098交互。排名公平集合是299共同编辑节点×7=2093交互，
因为两个缺失属于同一个human_071_E2B节点。每种模型都有完全相同299节点。
资源表仍统计全部2098有效交互，不丢掉其他方法该节点已有评分。
不是完整1000源数据；该Subset包含开发反馈，不能宣称未见人工金标准。

## 文件

- `scores_and_ranks.csv`：63行方法×指标原分及平均名次。
- `ranking_agreement.csv`：9指标排序关系和95%重采样区间。
- `pairwise_21_comparisons.csv`：9×21对，完整优劣/并列/稳定概率。
- `group_ranking_agreement.csv`：Real/Synthetic与五类视频。
- `bootstrap_rank_frequencies.json`：每模型名次频率（平均名次拆分至相邻位置，属可视化权重）。
- `production_runtime_memory.csv`：七worker真实有效请求耗时/显存峰值。
- `resources.json`：配置、独立部署数据、实际运行数据、Gemini token和未知资源。
- `analysis_provenance.json`：共同样例、来源文件、种子及抽样配置。
- `build_final_localvlm_result.py`：本次可复现生成脚本副本。

相关Spearman/Kendall均另用SciPy独立检查一致。
最强支持：本地裁判在EFA/PSR及其他主要指标上保留七模型相对比较，
而不是所有九指标精确评分等价。
尚不支持：声称Gemini硬件/能耗/费用高于本地；未取得相应服务端或账单数据。
可表述本地计算可控、单卡可运行、无需逐次远程API。
